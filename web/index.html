Grad no!

Abfahrtsanzeige für den Schreibtisch · Firmware __VERSION__ · ESP32-2432S028R („Cheap Yellow Display“)

1 · Installieren

Display per USB anschließen und auf den Knopf klicken. Funktioniert in Chrome und Edge am Computer.

Dein Browser unterstützt das nicht. Bitte Chrome oder Edge am Computer verwenden. Die Seite muss über https geöffnet werden.

Kein Anschluss in der Liste? Anderes USB-Kabel probieren (manche können nur laden). Windows braucht eventuell den CH340-Treiber. Hängt die Verbindung: BOOT gedrückt halten, kurz RST drücken, BOOT loslassen.

2 · WLAN einrichten

  1. Mit dem Handy ins WLAN GradNo-Setup (Passwort gradno123).
  2. Auf der Setup-Seite dein WLAN wählen und das Passwort eingeben.

3 · Haltestellen wählen

  1. http://grad-no.local öffnen (oder die IP, die am Display steht).
  2. Anmelden mit admin / gradno und das Passwort gleich ändern.
  3. Haltestelle suchen, hinzufügen, speichern.
